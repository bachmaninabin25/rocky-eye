# learntopic — 3 days of background, independent of the project code

| Day | File | Core idea |
|---|---|---|
| 1 | `day1_eclipses_and_thermal_emission.md` | an eclipse depth is a thermometer; bare rock vs atmosphere |
| 2 | `day2_bayesian_inference_mcmc.md` | likelihoods, integrating out nuisance parameters, MCMC, convergence, model comparison |
| 3 | `day3_jwst_detectors_and_systematics.md` | how MIRI reads, why light curves drift, modelling the noise |

Every `python` block runs on its own (numpy, scipy, emcee, all in the `rockyeye` env). Copy them
into a notebook, run them, then change the numbers and predict what happens before re-running.
Self-check questions are at the end of each day, answers below a separator.
